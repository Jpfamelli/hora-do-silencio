# A Hora do Silêncio

Jogo de terror em primeira pessoa que roda no navegador (Three.js, sem instalar nada).

**Jogar:** https://jpfamelli.github.io/hora-do-silencio/

Precisa de computador com teclado e mouse. Jogue de fone, no escuro.

WASD andar · SHIFT correr · C agachar · E interagir · F lanterna · R pilha · H curativo · G jogar garrafa · TAB diário · ESC pausa
